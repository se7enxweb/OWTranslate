# Changelog

## 1.3 (2026-10-22)

- Updated: The admin tab shows an icon: `[Topmenu_translate]` in
  `settings/menu.ini.append.php` names `Icon=translate`, which the admin4 design
  draws before the tab's name.
- Added: `composer.json` for the package `se7enxweb/owtranslate`, installed as
  `extension/owtranslate` by the Exponential legacy installer; requires PHP 8.0
  or later and the DOM extension.
- Updated: `ezinfo.php` (empty before) holds the `owtranslateInfo` class with
  version, copyright, license and website; `extension.xml` states the same
  version, copyright and the repository as its website.
- Updated: `README` becomes `README.md`, a complete guide with installation,
  configuration, usage examples, permissions, known limits and troubleshooting.
  `doc/INSTALL` points to it.

## 1.2 (2012-12-12)

- Release by Open Wide (see the git history for earlier changes).
